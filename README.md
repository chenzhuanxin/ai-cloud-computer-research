## 重要纠错与状态变更（已核验）

- 「华为云电脑」（早期消费级云电脑 App）与「华为云 Workspace / Flexus 云桌面」不是同一产品线，前者在营状态待确认
- 「海星云」（haixingyun）实为 VPS / 云服务器主机商，不是云电脑；与「海马云电脑」（pc.haimacloud.com）名字相近但无关
- UCloud 优刻得未检索到自有云桌面 / DaaS 产品线，未纳入主表
- Amazon WorkSpaces Pools：自 2026-07-31 起不再接受新客户（非持久桌面转向 WorkSpaces Applications）
- Microsoft Dev Box：功能迁移至 Windows 365，新注册自 2025-11-01 起不再接受
- VMware Horizon 随 Broadcom 分拆独立为 Omnissa；Frame 现由 Dizzion 运营；Paperspace 已被 DigitalOcean 收购
- Xbox Cloud Gaming 的 Game Pass Ultimate 自 2026-04-21 由 $29.99/月下调至 $22.99/月；GeForce NOW 自 2026-01-01 起、Xbox Cloud Gaming 自 2026-11 起分别加设每月游玩时长上限
