01核心结论

海外云电脑（云桌面 / DaaS）在 2025—2026 年出现了明显的三类分层：微软与 AWS 把「云 PC」做成了按人订阅的标准化产品；Citrix、Omnissa、Parallels、Workspot 等把「桌面交付」卖给大企业；Shadow、Paperspace、airgpu、GeForce NOW 则把「按小时租一台高性能机器」卖给了个人。

「按人订阅」正在取代「按主机租用」

微软把 Windows 365 做成按用户/月的固定档（Enterprise 起 $28.00/人/月，约 ¥199），并把 Dev Box 的开发机能力并入其中——Dev Box 已不接受新注册。AWS 同步收缩：WorkSpaces Pools 自 2026-07-31 起不再接受新客户，非持久化桌面转向 WorkSpaces Applications。买「一台云 PC」正在变成买「一个订阅席位」。

企业 DaaS 的真正成本在基础设施，不在许可

Azure Virtual Desktop 对已持有合格 Windows/M365/RDS 许可的用户免许可费，Citrix DaaS 约 $20/用户/月、Omnissa Horizon $12.50/用户/月、Parallels RAS $120/并发用户——但云主机、存储、出口流量都要另算。第三方估算：AVD 任务型用户约 $9–11/人/月，知识型 $36–40，专用高配可超过 $170。

消费级与云游戏：便宜，但开始"限时"

GeForce NOW 免费档仍在（单次 1 小时），Performance $9.99/月、Ultimate $19.99/月；Boosteroid 年付低至 €7.49/月（约 ¥58）。但 2026 年起风向变了：GeForce NOW 自 2026-01-01 起对 Performance/Ultimate 加设每月 100 小时上限，Xbox Cloud Gaming 自 2026-11 起按档位限 15/10/5 小时——「不限时」正在变成稀缺项。

052025—2026 关键节点

按公开可查的发布、调价与服务变更时点排列，用于理解竞争格局是怎么形成的。

2025 年是「收拢」的一年：Dev Box 不再开放新注册、能力并入 Windows 365，VMware Horizon 随 Broadcom 分拆更名 Omnissa，Paperspace 归入 DigitalOcean；2026 年则是「定价与限额调整」的一年——WorkSpaces Pools 停止接纳新客户、GeForce NOW 与 Xbox Cloud Gaming 相继设置每月时长上限。海外云电脑的主线，正在从「把 PC 搬上云」变成「按席位、按时长、按用量计费的订阅生意」。
